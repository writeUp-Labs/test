Hacked-Matrix

A custom terminal digital rain effect written in Ruby for Kali Linux, displaying " System Hacked ".

TO CLONE THE REPOSITORY;
git clone https://github.com/albi-cyber/Hacked-Matrix.git
cd Hacked-Matrix
TO MAKE IT EXECUTABLE:
chmod +x Hacked-Matrix
TO RUN;
./Hacked-Matrix
REQUIREMENTS:
Ruby installed on your system
